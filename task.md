# Задача: Auto Data Merger Tool

## Роль
Старший разработчик настольных приложений на Python (обработка и визуализация данных).

## Контекст
Настольное приложение объединяет несколько файлов продаж Excel/CSV и формирует сводный дашборд с графиками.

## Схема данных
- `date` (ГГГГ-ММ-ДД)
- `region`
- `product`
- `units_sold` (число)
- `unit_price` (число)

**Производное поле:** `revenue = units_sold * unit_price`

## Функциональные требования

### 1. Импорт файлов
- Выбор нескольких файлов: .xlsx, .xls, .csv
- Для Excel: выбор листа (по умолчанию: первый)
- Предпросмотр загруженных файлов (имя + количество строк)

### 2. Валидация и очистка
- Обязательные столбцы: date, region, product, units_sold, unit_price
- Преобразование date → datetime
- Приведение units_sold и unit_price к числовому типу
- Стандартизация заголовков (нижний регистр, подчёркивания)
- Удаление полностью пустых строк

### 3. Объединение
- Объединение всех строк в одну таблицу
- Удаление дубликатов (по всем столбцам или по ключу)

### 4. Сводки
- KPI-карточки: строки, единицы, выручка, диапазон дат
- Сводные таблицы: по продуктам, регионам, месяцам

### 5. Графики (matplotlib)
- Столбчатая: выручка по продуктам
- Столбчатая: выручка по регионам
- Линейный: динамика выручки (дни/месяцы)

### 6. Экспорт
- merged_output.xlsx (объединённые данные)
- summary_report.xlsx (сводные таблицы)
- PNG (графики, опционально)

## Технические ограничения
- Python 3.11+
- Tkinter (интерфейс)
- pandas (данные)
- openpyxl (Excel)
- matplotlib (графики)
- Архитектура: ui/, core/, reports/, charts/

## Критерии приёмки
- [ ] Приложение запускается: `python main.py`
- [ ] Загружает несколько файлов
- [ ] Показывает предпросмотр + количество строк
- [ ] Объединение с правильно рассчитанной выручкой
- [ ] Сводные таблицы отображаются
- [ ] Графики отображаются без ошибок
- [ ] Экспортированные Excel-файлы открываются
- [ ] Некорректный файл вызывает понятное сообщение об ошибке
