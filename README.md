# 🚀 Auto Data Merger Tool

**Профессиональный инструмент для объединения, анализа и визуализации данных о продажах.**

Приложение позволяет импортировать данные из различных источников (файлы Excel/CSV, Google Sheets, SQL-базы данных), автоматически объединять их, строить дашборды с KPI, графиками, прогнозами и корреляциями, а также экспортировать красивые PDF-отчёты.

---

## ✨ Основные возможности

### 📥 Импорт данных из разных источников
- **Локальные файлы**: CSV и Excel (`.xlsx`, `.xls`)
- **Google Sheets**: импорт из публичных таблиц по URL
- **SQL базы данных**: SQLite, PostgreSQL, MySQL

### 🧠 Умная обработка данных
- Автоматическое определение ролей столбцов (дата, регион, продукт, количество, цена)
- Ручной маппинг столбцов через удобный диалог
- Очистка данных: удаление дубликатов, обработка пропусков, валидация
- Поддержка опциональных полей: себестоимость, прибыль, клиент, менеджер

### 📊 Визуализация и аналитика
- **KPI-карточки**: общие продажи, выручка, прибыль, средний чек, период
- **Графики**: столбчатые и линейные диаграммы с подписями значений
- **Интерактивные графики Plotly**: наведение мыши, зум, сохранение в PNG/HTML
- **Zoom**: двойной клик по графику открывает окно с навигацией
- **Heatmap корреляций**: цветовая матрица связей между показателями
- **Прогнозирование**: линейная регрессия с расчётом точности (R²) и прогнозом на 1/3/6/12 месяцев
- **Сравнение периодов**: анализ роста/падения показателей в %

### 🎨 Настройка интерфейса
- **Тёмная и светлая темы** с мгновенным переключением
- **5 цветовых палитр** для графиков: классическая, пастельная, яркая, монохромная, корпоративная
- Все настройки сохраняются между запусками

### 📑 Сводные таблицы
- По продуктам, регионам, менеджерам, клиентам, месяцам
- Адаптивное отображение в зависимости от наличия данных

### 💾 Экспорт результатов
- **Excel**: объединённые данные и сводный отчёт с несколькими листами
- **PDF**: красивый отчёт для руководства с KPI, графиками и таблицами
- **PNG**: графики в высоком разрешении
- **HTML**: интерактивные графики Plotly

### 🔍 Фильтрация
- Фильтры по региону, продукту и периоду
- Мгновенное обновление дашборда

## 📦 Сборка в .exe (PyInstaller)

### Простая сборка (рекомендуется):

```bash
pyinstaller --noconfirm --onedir --windowed \
  --name "AutoDataMerger" \
  --hidden-import pandas --hidden-import openpyxl \
  --hidden-import matplotlib --hidden-import plotly \
  --hidden-import sqlalchemy --hidden-import psycopg2 --hidden-import pymysql \
  --hidden-import numpy --hidden-import fpdf2 \
  --hidden-import core.* --hidden-import ui.* --hidden-import reports.* \
  --collect-all matplotlib --collect-all plotly --collect-all pandas \
  main.py
```

Результат появится в папке `dist/AutoDataMerger/`.

### Распространение:
- Запакуйте **всю папку** `dist/AutoDataMerger/` в ZIP
- Пользователь распакует и запустит `AutoDataMerger.exe`
- ⚠️ Не перемещайте `.exe` отдельно от папки

## 📋 Формат входных данных

### Обязательные столбцы (минимум 5):
| Роль | Примеры названий | Описание |
|------|------------------|----------|
| 📅 Дата | `date`, `дата`, `order_date` | Дата продажи |
| 🌍 Регион | `region`, `регион`, `city` | Город/регион |
| 📦 Продукт | `product`, `товар`, `item` | Наименование товара |
| 🔢 Количество | `units_sold`, `количество`, `qty` | Продано единиц |
| 💰 Цена | `unit_price`, `цена`, `price` | Цена за единицу |

### Опциональные столбцы (улучшают аналитику):
| Роль | Описание |
|------|----------|
| 💵 Себестоимость | Для расчёта прибыли |
| 📈 Прибыль | Если уже рассчитана |
| 👤 Клиент | Для анализа по покупателям |
| 👔 Менеджер | Для анализа по продавцам |

Если названия столбцов отличаются — приложение предложит выбрать соответствие вручную.
