# План реализации

## Основная логика (core)
- loader.py — чтение .csv, .xlsx, .xls
- validator.py — стандартизация заголовков, проверка обязательных столбцов
  (date, region, product, units_sold, unit_price), преобразование типов, удаление пустых строк
- merger.py — объединение с удалением дубликатов, расчёт revenue

## Отчётность (reports)
- kpi.py — всего строк, единиц, выручки, диапазон дат
- summaries.py — сводные таблицы (по продукту, региону, месяцам)

## Визуализация (charts)
- plots.py — выручка по продуктам, по регионам, динамика выручки

## Интерфейс (ui)
- main_window.py — главное окно, навигация, фоновый обработчик
- file_panel.py — импорт файлов и предпросмотр
- dashboard_panel.py — KPI, сводки, графики
- export_panel.py — экспорт Excel и PNG

## План проверки
- scripts/generate_sample_data.py создаёт корректные и некорректные файлы в test_data/
- Ручная проверка: запуск, импорт нескольких файлов, графики, экспорт, ошибки валидации
