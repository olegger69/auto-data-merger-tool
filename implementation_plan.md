# План реализации Auto Data Merger Tool

## Этапы разработки

### Этап 1: Базовая структура ✅
- Создание структуры папок
- Настройка requirements.txt
- Базовое окно Tkinter
- Первый Git-коммит

### Этап 2: Загрузка файлов ✅
- core/loader.py: загрузка CSV и Excel
- Поддержка выбора листа для Excel
- Предпросмотр файлов

### Этап 3: Валидация и очистка ✅
- core/validator.py: валидация обязательных столбцов
- Преобразование типов (date, numeric)
- Стандартизация заголовков
- Удаление пустых строк

### Этап 4: Объединение данных ✅
- core/merger.py: объединение нескольких файлов
- Удаление дубликатов
- Расчёт revenue

### Этап 5: Отчёты и KPI ✅
- reports/kpi.py: расчёт метрик
- reports/summaries.py: сводные таблицы

### Этап 6: Визуализация ✅
- charts/plots.py: построение графиков
- Столбчатые диаграммы
- Линейный график

### Этап 7: Интерфейс ✅
- ui/main_window.py: главное окно с вкладками
- ui/file_panel.py: панель импорта
- ui/dashboard_panel.py: дашборд с KPI, таблицами, графиками
- Фоновая обработка (threading)

### Этап 8: Экспорт ✅
- ui/export_panel.py: панель экспорта
- Экспорт в Excel (merged_output.xlsx, summary_report.xlsx)
- Экспорт графиков в PNG

### Этап 9: Документация ✅
- README.md
- task.md
- scripts/generate_sample_data.py
- .gitignore
